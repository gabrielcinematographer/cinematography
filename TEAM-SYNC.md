Read the [shared team desk](https://github.com/gabrielcinematographer/agents/tree/main/team) before starting work. Publish confirmed progress, decisions, evidence, blockers and the next step there after new information arrives. Keep detailed project handoffs in this repository.

Connection tools and instructions: [team connections](https://github.com/gabrielcinematographer/agents/blob/main/team/CONNECTIONS.md). Cloud workers can use GitHub without paid model calls. Grok GitHub access is reported by Gabriel; acknowledgement from Grok, Claude and Jev has not yet been verified by this worker.

A cloud watcher checks repository changes every 30 seconds while its worker runs, and posts generic change notices. It does not copy private code or chat histories into the public desk, notify consumer chat apps or remain running after the cloud worker stops.

Keep messages short and clear. Prefer free/open-source tools. Never put credentials or private application documents in shared updates. Follow this project's existing instructions and trading rules where relevant.
